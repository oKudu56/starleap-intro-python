Dodge! — Mini Random Game

How to run

1. Start a static server in the workspace or open the file via a local server. Example (PowerShell):

```powershell
cd chapters/mini_random_game
python -m http.server 8000
```

2. Open in a browser:

http://localhost:8000/chapters/mini_random_game/

Controls
- Space: Start the game
- A / D  or ArrowLeft / ArrowRight: Move left / right
- R: Restart after Game Over

Description
- Simple one-player canvas game where falling blocks appear from the top. Survive as long as you can to increase your score.
